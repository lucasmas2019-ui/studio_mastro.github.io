Proyecto 03 · Desarrollo web

Sitio Web Turístico San Bernardo del Tuyú

Sitio web informativo sobre el destino turístico San Bernardo del Tuyú, desarrollado en Visual Studio Code con HTML y CSS, con un diseño centrado en la experiencia del usuario y la claridad de la información.

Rol Diseño y desarrollo front-end
Herramientas HTML, CSS, VS Code
Año 2026
Tipo Sitio web informativo
san-bernardo-del-tuyu.html
01

El desafío

Organizar información turística (playas, actividades, alojamiento) en un sitio claro y navegable, con una jerarquía visual que invite a explorar el destino.

02

El proceso

Se definieron las secciones informativas principales, se trabajó una paleta cálida asociada al destino costero y se maquetó el sitio en HTML y CSS puro dentro de Visual Studio Code, priorizando la experiencia de usuario.

03

El resultado

Un sitio turístico completo y ordenado, pensado para orientar a un visitante interesado en conocer San Bernardo del Tuyú.

Herramientas usadas
  • HTML5
  • CSS3
  • Visual Studio Code
  • Experiencia de usuario
